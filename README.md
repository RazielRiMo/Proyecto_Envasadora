# Proyecto_Envasadora
Programacion de una envasadora cuyos sensores y actuadores sean controlados por la stm32 nucleo 401RE con el framework de arduino en PlatdformIO, la telemetria y comunicacion con la esp32 wroom y la interfas y control del sistema en pc por tkinter y socket via wifi ademas de su supervicion via bluethoot low energy(BLE) por el telefono

#STM32
nucleo 401RE para control de sensores y actuadores

#ESP32
ESP32WROOM para control de telemetria y manejo de la STM32 por medio de comunicacion UART
